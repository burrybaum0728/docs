picobean uses a small set of terms across its features. Learn them once, and every page in this guide becomes easier to follow. This page groups those terms by product area and links to the page that covers each one in depth.

## Workspace and plans

| Term | Meaning |
| --- | --- |
| **Organization** | Your team's shared workspace. Members share folders, memos, campaigns, and contact history. |
| **Plan** | Your subscription tier. It decides which features are unlocked, for example Basic or Enterprise. |
| **Plugin** | A feature set that you turn on in Settings: **Influencer Affiliate** or **Trend Research**. |
| **Credit** | The usage unit consumed by searches and agent requests. |

Learn more in [Plans and plugins](/get-started/plans-and-plugins).

## Account search

| Term | Meaning |
| --- | --- |
| **Prompt** | A plain-language description of the creators or content you want. |
| **Criteria** | The structured filters that the agent extracts from your prompt. |
| **Row limit** | How many matching accounts the agent collects. |
| **Saved folder** | A list of creators you saved for later. |
| **Memo** | A team note attached to a creator. |

Learn more in [AI search](/account-search/ai-search).

## Campaigns

| Term | Meaning |
| --- | --- |
| **Campaign** | One seeding program, with its own brief, roster, emails, and budget. |
| **Unpaid / Paid seeding** | Gifted product only, or product plus a fee. |
| **Roster status** | A creator's stage: Prospect, Contacted, Negotiating, Confirmed, Product sent, Posted, or Not participating. |
| **Deal** | A fee negotiation with one creator, recorded in a ledger. |
| **Content guideline** | Must-include and must-avoid rules used to review drafts. |

Learn more in [Campaign overview](/campaigns/overview).

## Email outreach

| Term | Meaning |
| --- | --- |
| **Linked mailbox** | Your Gmail or Outlook account, used to send campaign emails. |
| **Template** / **Variable** | A reusable email with placeholders such as `{{creator_name}}`. |
| **Sequence** | An intro email plus automatic no-reply follow-ups. |
| **Seeding agent** | The AI that reads replies and drafts or sends responses. |
| **Approval queue** | Agent drafts waiting for your OK. |

Learn more in [Connect a mailbox](/email/connect-mailbox).

## Performance and trends

| Term | Meaning |
| --- | --- |
| **My account / Competitor / My influencer** | The three content sources tracked in the Performance Dashboard. |
| **Gain %** | The change compared with the previous period. |
| **Content tag** | An AI label such as Paid, Affiliate, or Hook. |
| **Trend** / **Meme** | A rising topic, hashtag, or format detected by Trend Research. |

Learn more in [Performance Dashboard](/performance/dashboard) and [Trends](/trends/trends).
