picobean controls access to features in two ways: **plugins** decide which tabs appear in your sidebar, and your **billing plan** decides which capabilities you can use inside those tabs. You can turn on several plugins at once, and every account starts on the Free plan. This page explains both and lists which plan each feature needs.

## Key concepts

| Term | Meaning |
| --- | --- |
| **Plugin** | A feature set that adds tabs to the sidebar. |
| **Plan** | Your organization's subscription level: Free, Basic, or Enterprise. |
| **Locked feature** | A feature your current plan does not include. picobean shows an upgrade message when you try to use it. |

### Turn plugins on or off

<Steps>
  <Step title="Open Settings">
    Select **Settings** in the sidebar. The **Account** tab opens.
  </Step>
  <Step title="Find Plugin Selection">
    Find the **Plugin Selection** card.
  </Step>
  <Step title="Choose plugins">
    Check the plugins you want. Active plugins are labeled **In use**.
  </Step>
  <Step title="Save">
    Select **Save**. The sidebar updates right away.
  </Step>
</Steps>

<Note>
  Settings and billing pages are always available, whichever plugins are on. If you turn a plugin off, its tabs disappear and their pages cannot be opened by URL.
</Note>

## Plans

Your organization's plan is shown in **Settings**. Prices and credits are listed on the [Billing](/account/billing) page.

### Feature availability by plan

| Feature | Free | Basic | Enterprise |
| --- | --- | --- | --- |
| Saved lists, folders, bookmarks, memos | Yes | Yes | Yes |
| Translation | Yes | Yes | Yes |
| AI account search | No | Yes | Yes |
| Monitor dataset and add more rows | No | Yes | Yes |
| CSV download | No | Yes | Yes |
| Full content analysis | No | Yes | Yes |
| Viral content dashboard and views over time | No | Yes | Yes |
| Campaign management | No | No | Yes |
| Mailbox management and email send | No | No | Yes |
| Team member invitation | No | No | Yes |
| Private DB (My accounts) | No | No | Yes |
| Content upload | No | No | Yes |

When you try a feature your plan does not include, picobean shows an upgrade message. For Enterprise-only features it reads: "This feature is only available on the Enterprise plan."

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I use more than one plugin?">
    Yes. Turn on Influencer Affiliate and Trend Research together, and the sidebar shows the tabs for both.
  </Accordion>

  <Accordion title="How do I upgrade my plan?">
    Go to **Settings** > **Usage & Billing** and choose a plan. See [Billing](/account/billing). If you cannot see billing options, contact your organization admin.
  </Accordion>
</AccordionGroup>
