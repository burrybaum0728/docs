When you submit a prompt, the picobean agent converts it into **criteria**: a set of structured conditions that decide which creators appear in your results. This page explains how to review those criteria and edit them, and how to add filters to narrow your results further.

## Key concepts

| Term | Meaning |
| --- | --- |
| **Criterion** | One condition, such as "Followers between 50K and 300K" or "Country is United States". |
| **Filter chip** | A criterion shown as a small tag above the results. Select it to see or change its value. |
| **Criteria match** | For each result, whether the account meets each criterion. Use this to judge result quality. |
| **Excluded brands** | Brands to filter out, so you skip creators who recently worked with them. |

## Review the criteria

<Steps>
  <Step title="Open the criteria">
    After you submit a search, select **Criteria** or **See full criteria** above the results.
  </Step>
  <Step title="Check each criterion">
    Confirm that the agent read your prompt correctly. For example, check that "mid-tier" became the follower range you expected.
  </Step>
  <Step title="Edit or remove">
    Select **Edit** to change a value. Select **Remove criterion** to delete one.
  </Step>
  <Step title="Add a criterion">
    Select **Add Criteria** or **Add filter**, choose a field, set its value, and select **Apply**.
  </Step>
</Steps>

To rewrite the whole request instead, select **Edit prompt**, then submit the search again.

## Available filters

| Filter | What it does |
| --- | --- |
| **Platform** | The social platform to search. |
| **Followers** | Minimum and maximum follower count. |
| **Engagement rate** | Minimum engagement rate. |
| **Countries** | The creator's country. |
| **Categories** / **Sub-categories** | The creator's content niche. |
| **Primary content language** | The main language the creator posts in. |
| **Creator persona** | The type of creator, for example a reviewer or a lifestyle vlogger. |
| **Hashtags** / **Keyword** | Hashtags or keywords that appear in the creator's content. |
| **Brands** / **Excluded brands** | Brands the creator has worked with, or brands to exclude. |
| **Last Sponsored** | When the creator last posted sponsored content. |
| **Latest upload from** / **through** | A date range for the creator's most recent upload, which filters out inactive accounts. |
| **Has email** / **Has contact** | Only show creators with public contact details. |
| **Verified** / **Official Account** | Only show verified or official accounts. |
| **Exclude contacted accounts** | Hide creators that anyone in your organization has already contacted. |

<Tip>
  Turn on **Has email** if you plan to run email outreach. Turn on **Exclude contacted accounts** so you don't contact the same creator twice across campaigns.
</Tip>

## Sort the results

Use **Sort by** to order results, for example by **Relevance**, **Followers**, or **Engagement rate**. Set **Sort order** to **Ascending** or **Descending**.

## Common questions

<AccordionGroup>
  <Accordion title="The agent misread my prompt. What should I do?">
    Edit the wrong criterion directly. That is usually faster than rewriting the prompt. If several criteria are wrong, select **Edit prompt** and add more specific details.
  </Accordion>

  <Accordion title="I get too few results.">
    Widen the follower range, remove optional criteria such as language or persona, or add more countries.
  </Accordion>
</AccordionGroup>
