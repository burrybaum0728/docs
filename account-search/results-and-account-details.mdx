When a search finishes, picobean shows the matching creators in a results table. From there you can sort and narrow the list, open each creator's details, request more rows, keep the search running on a schedule, and move promising creators into Saved or a campaign.

## Key concepts

| Term | Meaning |
| --- | --- |
| **Results table** | The list of creators that match your search, with key metrics in each row. |
| **Account details** | A panel with a creator's full data: **Overview**, **Sponsor History**, and **Memo**. |
| **Add more rows** | Raise the row limit of a finished search to get more matching creators. Uses credits. |
| **Monitor dataset** | Run the same search again on a schedule so new matches are added over time. Uses credits. |
| **Request Admin to add to DB** | Ask the picobean team to add creators that seem to be missing from the database. |

## Work with the results table

<Steps>
  <Step title="Check the criteria">
    Select **See full criteria** to review the conditions behind the results. To change them, see [Criteria and filters](/account-search/criteria-and-filters).
  </Step>
  <Step title="Sort">
    Open **Sort by** and choose **Relevance**, **Viral**, **Name**, **Followers**, **Last Fetched**, or **Last Sponsored**. Choose **Descending** or **Ascending** under **Order**, then select **Apply**.
  </Step>
  <Step title="Search within results">
    Use the search box above the table to filter the current results by account name, brand, or hashtag. This does not run a new search.
  </Step>
  <Step title="Select rows">
    Check rows to act on several creators at once. Use the header checkbox to select every row on the page, or select all results across pages.
  </Step>
</Steps>

| Column | What it shows |
| --- | --- |
| **Followers** | The creator's follower count. |
| **ER** | Engagement rate: audience interaction relative to follower count. |
| **Last Sponsored** | The most recent brand collaboration picobean detected. |
| **Last Fetched** | When picobean last updated this creator's data. |

<Tip>
  Select **Content Trend** to open the Trends page with the same prompt and see what content is performing for that topic.
</Tip>

## Open account details

Select a row to open the creator's details. Use the previous and next arrows to move through results without closing the panel, and press **Escape** to close it.

| Tab | What you see |
| --- | --- |
| **Overview** | Performance badges, account information, linked accounts, hashtags, sponsored categories, a content preview, and a performance chart. |
| **Sponsor History** | Detected brand collaborations with dates and sponsored items. |
| **Memo** | Notes your team keeps about this creator. |

Turn on **Translate** to translate creator names, hashtags, sponsored items, and content previews between Korean and English. Only creator content is translated, not the app interface.

## Add more rows

<Steps>
  <Step title="Open Add more rows">
    Select **Add more rows** above the table. **Total results found** shows how many matching creators are available.
  </Step>
  <Step title="Choose a row limit">
    Pick a preset or type a number.
  </Step>
  <Step title="Request">
    Select **Request**. The button shows the credit cost, and the new rows are added to the current table.
  </Step>
</Steps>

## Monitor a search

<Steps>
  <Step title="Open the subscription">
    Select **Add Subscription** next to the search title. If the search is already monitored, the button reads **Edit**.
  </Step>
  <Step title="Set the schedule">
    Choose how often the search runs and how many new rows to add each time.
  </Step>
  <Step title="Save">
    Select **Save**. New matches appear in the results as each run completes.
  </Step>
</Steps>

<Note>
  Add more rows, Monitor dataset, and CSV download require the Basic plan or higher. Monitoring costs 1 credit per day. See [Billing](/account/billing).
</Note>

## Request missing creators

If creators you expected are missing, select **Request Admin to add to DB** below the results. The button changes to **Request Sent**. Newly added creators appear in later searches.

## Save, export, and add to campaigns

- **Save**: Select the bookmark icon on a row or in the details panel, then choose a folder or create one. See [Saved](/influencer/saved).
- **Export CSV**: Select the download icon above the table to save the results as a CSV file.
- **Add to a campaign**: Add selected creators to a campaign roster. See [Roster and deals](/campaigns/roster-and-deals). (Enterprise)
