picobean의 대량 이메일 플로우를 사용하면 한 번의 동작으로 수십에서 수백 명의 크리에이터에게 개인화된 아웃리치를 전달할 수 있습니다. 저장된 목록, 붙여넣은 이메일, CSV 업로드에서 수신자를 선택하고, 개인화 미리보기로 모든 메시지를 확인한 후 즉시 발송하거나 예약할 수 있습니다. 또한 크리에이터가 답변하지 않을 때 자동으로 후속 조치를 취하는 이메일 시퀀스를 구축할 수 있습니다. 이 페이지에서는 수신자 선택부터 배달 추적까지 전체 워크플로우를 다룹니다.

<Note>
  대량 이메일 발송 및 시퀀스는 **Enterprise** 요금제에서 사용할 수 있습니다. 해당 옵션이 보이지 않으면 [Billing](/ko/account/billing) 페이지에서 요금제를 확인하거나 관리자에게 문의하세요.
</Note>

## 핵심 개념

| 용어 | 의미 |
| --- | --- |
| 수신자 선택기 | 저장된 계정, 목록, 붙여넣은 이메일, CSV 업로드에서 이메일 수신자를 선택하는 패널입니다. |
| 대량 확인 패널 | 선택된 수신자 목록, 첨부파일, 누락된 값 경고를 표시하고, 개인화 미리보기를 보여주는 최종 검토 화면입니다. |
| 예약 발송 | 날짜, 시간, 타임존을 선택하는 지연 발송입니다. |
| 시퀀스 | 수신자가 답변 여부에 따라 발송되는 타이밍이 정해진 일련의 이메일(소개 + 후속)입니다. |
| 발송 완료 수신자 | 이메일을 받은 사람과 열람, 반송, 스팸 표시 여부를 보여주는 내역 화면입니다. |

## 수신자 선택

<Steps>
  <Step title="발송 플로우 열기">
    **Campaigns**로 이동해 캠페인을 연 다음, **Send emails**를 클릭하여 대량 발송 플로우를 시작합니다.
  </Step>
  <Step title="소스 선택">
    **Recipient selector**에서 소스를 선택하세요:

    | 소스 | 설명 |
    | --- | --- |
    | Saved | 검색이나 Discover에서 이미 picobean 계정에 저장한 인플루언서입니다. |
    | List | 이전에 만들어 둔 사전 구축된 수신자 목록입니다. |
    | Pasted | 텍스트 영역에 직접 입력하거나 붙여넣은 이메일 주소입니다. |
    | CSV | 이메일, 이름, 커스텀 변수 컬럼이 포함된 스프레드시트 업로드입니다. |
  </Step>
  <Step title="수신자 추가">
    원하는 행을 선택합니다. 테이블 체크박스를 사용하여 개별 크리에이터를 선택하거나, 표시된 모든 행을 선택할 수 있습니다. 선택한 총 수가 패널 상단에 표시됩니다.
  </Step>
  <Step title="커스텀 값 설정">
    템플릿에 커스텀 변수(예: `{{fee}}`)를 사용하는 경우, 계속하기 전에 테이블 컬럼에 각 수신자의 값을 입력하세요.
  </Step>
</Steps>

## 발송 전 검토 및 확인

**Bulk confirm** 패널은 이메일이 메일박스를 떠나기 전 최종 안전 검사입니다.

<Steps>
  <Step title="수신자 목록 검토">
    확인 패널은 각 수신자의 소스(Saved, CSV, Pasted, List)와 함께 목록을 보여줍니다. 체크박스를 사용하여 포함하지 않을 사람을 제거할 수 있습니다.
  </Step>
  <Step title="누락된 값 확인">
    템플릿 변수에 선택된 수신자의 값이 없으면 패널에서 오류를 강조합니다. 모든 선택된 행이 사용된 모든 변수에 대해 값을 가질 때까지 발송이 차단됩니다. 누락된 값을 입력하거나 해당 행을 선택 해제하세요.
  </Step>
  <Step title="개인화 이메일 미리보기">
    **Personalized preview** 섹션을 열고 드롭다운에서 수신자를 선택하세요. 모든 변수가 대체된 정확한 제목과 본문을 볼 수 있습니다. 수신자를 전환하여 이름, 수수료, 커스텀 필드가 올바르게 해석되는지 확인하세요.
  </Step>
  <Step title="첨부파일 검토">
    템플릿 또는 이번 발송에 첨부파일이 포함된 경우, 파일 크기와 함께 목록에 표시됩니다. 총합은 25MB, 10개 파일 이하여야 합니다.
  </Step>
  <Step title="CC 또는 BCC 추가">
    **Add CC & BCC**를 클릭하여 팀원을 포함하세요. 타이핑을 시작하면 picobean이 이름 또는 이메일로 조직 내 다른 구성원을 제안합니다.
  </Step>
</Steps>

<Warning>
  수신자를 선택 해제하면 해당 수신자가 이번 발송에서만 제거됩니다. 캠페인 명단에서 삭제되지는 않습니다. 캠페인에서 완전히 제거하려면 [캠페인 명단](/ko/campaigns/roster-and-deals)을 사용하세요.
</Warning>

## 즉시 발송 또는 예약

수신자 목록과 미리보기가 올바르게 확인되었으면, 이메일을 전달할 시점을 선택하세요.

<Steps>
  <Step title="즉시 발송">
    **Send now**를 클릭합니다. picobean이 메시지를 대기열에 넣고 배달을 시작합니다. 배치가 제출되는 동안 스피너가 표시됩니다.
  </Step>
  <Step title="나중을 위해 예약">
    **Schedule send**를 클릭하여 **Schedule activation** 모달을 엽니다. 다음을 선택합니다:

    | 필드 | 설정 내용 |
    | --- | --- |
    | Time zone | 발송이 따를 도시 타임존 |
    | Date | 오늘, 내일, 또는 미래 날짜 |
    | Time | 24시간 또는 12시간 형식의 시와 분 |
  </Step>
  <Step title="예약 확인">
    날짜, 시간, 타임존을 선택한 후 모달에서 **Schedule**을 클릭합니다. 캠페인이 보류 중인 예약 발송으로 업데이트됩니다.
  </Step>
</Steps>

<Warning>
  타임존을 다시 확인하세요. 예약은 선택한 도시 타임존을 따르므로, 사용자의 로컬 시간과 다를 수 있습니다.
</Warning>

## 이메일 시퀀스 설정

이메일 시퀀스는 수신자 행동에 따라 자동으로 발송되는 일련의 타이밍이 정해진 메시지입니다. 첫 번째 단계는 항상 소개 이메일입니다. 사용자가 설정한 지연 시간 후에 크리에이터가 답변하지 않은 경우에만 후속 단계가 발송됩니다.

<Steps>
  <Step title="시퀀스 패널 열기">
    캠페인 내에서 **Email sequence** 패널로 전환합니다.
  </Step>
  <Step title="단계 추가">
    첫 번째 단계는 **Intro**이며 제거할 수 없습니다. **Add step**을 클릭하여 후속 이메일을 생성합니다.
  </Step>
  <Step title="지연 시간 설정">
    각 후속 단계에 대해 분 또는 시간 단위로 **Wait** 기간을 선택하세요. 이전 단계 이후 크리에이터가 답변하지 않은 경우에만 후속 이메일이 발송됩니다.
  </Step>
  <Step title="각 템플릿 작성">
    단계를 클릭하여 편집기를 열고 제목과 본문을 작성합니다. 단계를 재사용 가능한 템플릿으로 저장하거나, 라이브러리의 기존 템플릿을 사용할 수 있습니다.
  </Step>
  <Step title="단계 활성화 또는 비활성화">
    각 단계 옆의 토글 스위치를 사용하여 활성화하거나 일시 중지합니다. 비활성화된 단계는 건너뜁니다.
  </Step>
  <Step title="시퀀스 저장">
    **Save sequence**를 클릭합니다. 캠페인이 전체 시퀀스를 저장하고 설정한 지연 시간에 따라 발송합니다.
  </Step>
</Steps>

## 발송 진행 상황 및 발송 완료 수신자 추적

발송 또는 예약 후, picobean은 각 메시지의 결과를 추적합니다.

<Steps>
  <Step title="발송 완료 수신자 보기">
    캠페인 내에서 **Sent recipients** 탭을 엽니다. 이 캠페인에서 이메일을 받은 모든 사람과 플랫폼 아이콘, 이메일 주소가 목록에 표시됩니다.
  </Step>
  <Step title="배달 상태 확인">
    각 행에 상태 배지가 표시됩니다:

    | 상태 | 의미 |
    | --- | --- |
    | Opened | 수신자가 이메일을 열람했습니다 |
    | Not opened | 배달되었으나 아직 열람하지 않았습니다 |
    | Bounced | 이메일을 배달할 수 없었습니다 |
    | Spammed | 수신자의 서버가 메시지를 스팸으로 표시했습니다 |
  </Step>
  <Step title="대화 열기">
    수신자를 클릭하면 대화 타임라인이 열립니다. 전체 메시지 내역, 답변, 실행된 모든 후속 단계를 볼 수 있습니다.
  </Step>
</Steps>

발송이 진행 중이면 배치가 완전히 대기열에 들어갈 때까지 인터페이스에 로딩 상태가 표시됩니다. 메시지가 백그라운드에서 배달되는 동안 picobean에서 계속 작업할 수 있습니다.
