picobean 템플릿 편집기를 사용하면 아웃리치 이메일을 한 번 작성하여 여러 캠페인에서 재사용할 수 있습니다. 크리에이터 이름과 커스텀 필드 같은 변수로 각 메시지를 개인화하고, 공유 서명으로 모든 캠페인 이메일을 일관되게 유지할 수 있습니다. 이 페이지에서는 템플릿 작성, 변수 및 첨부파일 추가, 서명 관리 방법을 설명합니다.

## 핵심 개념

| 용어 | 의미 |
| --- | --- |
| 템플릿 | 여러 캠페인에서 재사용할 수 있는 저장된 제목과 본문입니다. |
| 변수 | 발송 시 수신자별로 채워지는 `{{creator_name}}` 같은 플레이스홀더입니다. |
| 서명 토큰 | 모든 이메일 끝에 공유 서명을 삽입하는 `{{signature}}` 플레이스홀더입니다. |
| 커스텀 컬럼 | 사용자가 정의하는 수신자별 값(예: `fee`)으로, 발송 테이블에 추가합니다. |
| 개인화 미리보기 | 변수가 해석된 후 특정 수신자가 받게 될 최종 이메일을 보여주는 나란히 보기 화면입니다. |

<Note>
  이메일 템플릿, 서명, 발송 기능은 **Enterprise** 요금제에서 사용할 수 있습니다. 해당 기능이 보이지 않으면 [Billing](/ko/account/billing) 페이지에서 요금제를 확인하거나 관리자에게 문의하세요.
</Note>

## 새 템플릿 작성하기

<Steps>
  <Step title="편집기 열기">
    **Campaigns**로 이동해 캠페인을 연 다음, **Email sequence** 패널에서 **Add step**을 클릭하여 템플릿 편집기를 엽니다. **Bulk email** 발송 플로우에서 **New template**을 선택하여 시작할 수도 있습니다.
  </Step>
  <Step title="제목 작성">
    **Subject** 필드에 제목을 입력합니다. 변수를 타이핑하면 파란색으로 강조 표시됩니다.
  </Step>
  <Step title="본문 작성">
    메시지 본문을 클릭하고 아웃리치 텍스트를 작성합니다. 툴바를 사용하여 서식, 링크, 이모지, 이미지 또는 첨부파일을 추가합니다.
  </Step>
  <Step title="개인화 변수 추가">
    툴바에서 **Personalize** 버튼을 클릭합니다. 기본 변수 중에서 선택하세요:

    | 변수 | 토큰 | 채워지는 값 |
    | --- | --- | --- |
    | Creator name | `{{creator_name}}` | 인플루언서의 표시 이름 또는 핸들 |
    | Name | `{{name}}` | 이름 또는 이메일 주소의 @ 앞부분 |

    **커스텀 변수**(예: `{{fee}}`)를 정의하고, 설정 중에 모든 수신자에 대한 값 컬럼을 추가할 수도 있습니다.
  </Step>
  <Step title="개인화 결과 미리보기">
    저장하기 전에 **Personalized preview** 패널에서 드롭다운으로 수신자를 선택하세요. 모든 변수가 실제 값으로 대체된 정확한 제목과 본문이 렌더링됩니다.
  </Step>
  <Step title="템플릿 저장">
    템플릿에 이름을 지정하고 **Save**를 클릭합니다. 향후 캠페인을 위한 템플릿 라이브러리에 표시됩니다.
  </Step>
</Steps>

## 커스텀 변수 추가 또는 수정

커스텀 변수는 기본 제공 필드 이상으로 개인화할 수 있게 해줍니다. 일반적인 사용 사례는 각 크리에이터별 맞춤 오퍼 또는 수수료를 포함하는 것입니다.

<Steps>
  <Step title="변수 선택기 열기">
    편집기 툴바에서 **Personalize**를 클릭하고 팝오버의 하단으로 스크롤합니다.
  </Step>
  <Step title="변수 이름 지정">
    **Add a value column for every recipient** 필드에 `fee` 같은 변수 이름을 입력합니다. 문자, 숫자, 밑줄만 사용할 수 있습니다.
  </Step>
  <Step title="토큰 삽입">
    **Add**를 클릭하면 커서 위치에 `{{fee}}` 토큰이 삽입됩니다.
  </Step>
  <Step title="설정 중 값 입력">
    대량 발송 설정 시 수신자 테이블에 **fee** 컬럼이 나타납니다. 각 크리에이터의 값을 입력하면 이메일이 올바르게 해석됩니다.
  </Step>
</Steps>

<Warning>
  선택한 수신자에게 변수 값이 없으면, 모든 선택된 행에 값이 입력될 때까지 발송이 차단됩니다. 발송 전에 **Bulk confirm** 패널을 확인하세요.
</Warning>

## 서명 관리

picobean은 모든 캠페인 이메일에 하나의 공유 서명을 사용합니다. 모든 편집기 또는 캠페인 설정에서 서명을 만들고 관리할 수 있습니다.

<Steps>
  <Step title="서명 선택기 열기">
    모든 편집기에서 툴바의 **Signature template** 버튼(펜 아이콘)을 클릭합니다.
  </Step>
  <Step title="생성 또는 수정">
    서명이 없으면 **Create signature**를 클릭합니다. 이미 있으면 **Edit**을 클릭하여 서명 편집기를 엽니다.
  </Step>
  <Step title="콘텐츠 추가">
    마무리 인사를 입력하고, 링크를 추가하고, 로고나 배너 이미지를 업로드하세요. 편집기는 굵게, 기울임, 밑줄, 링크를 지원합니다.
  </Step>
  <Step title="이미지 크기 조정">
    편집기에서 이미지를 클릭하여 선택한 뒤, 파란색 모서리 핸들을 드래그하여 크기를 조정합니다. 너비가 저장되어 이메일 클라이언트에서 올바르게 렌더링됩니다.
  </Step>
  <Step title="저장">
    **Save signature**를 클릭합니다. 서명이 저장되며, `{{signature}}` 토큰으로 모든 템플릿에 삽입할 수 있습니다.
  </Step>
</Steps>

서명 선택기에는 실시간 미리보기도 표시됩니다. 준비가 되면 미리보기를 클릭하여 현재 이메일 본문 끝에 `{{signature}}` 토큰을 삽입합니다.

## 템플릿에 파일 첨부

파일을 저장된 템플릿에 영구적으로 첨부하거나, 단일 발송 중에 임시로 첨부할 수 있습니다.

| 첨부 유형 | 동작 | 제한 |
| --- | --- | --- |
| 저장된 첨부파일 | 템플릿에 저장되어 사용할 때마다 포함 | 최대 10개, 총 25MB |
| 인라인 이미지 | 본문에 직접 붙여넣거나 삽입 | 8MB 초과 시 자동 크기 조정 |
| 신규 업로드 | 발송 중 추가되어 해당 배치에서만 전송 | 저장된 첨부파일과 동일한 제한 |

파일을 추가하려면 툴바의 **Add attached files** 버튼을 클릭합니다. 지원 형식은 PDF, DOC, DOCX, TXT, JPG, PNG, GIF입니다.
