프롬프트를 제출하면 picobean 에이전트는 이를 **criteria**(조건)으로 변환합니다. 이는 결과에 어떤 크리에이터가 나타날지 결정하는 구조화된 조건 집합입니다. 이 페이지에서는 해당 조건을 검토하고 편집하는 방법, 그리고 필터를 추가하여 결과를 더욱 좁히는 방법을 설명합니다.

## 핵심 개념

| 용어 | 의미 |
| --- | --- |
| **Criterion** | 하나의 조건입니다. 예: "Followers between 50K and 300K" 또는 "Country is United States". |
| **Filter chip** | 결과 상단에 표시되는 작은 태그 형태의 조건입니다. 선택하면 값을 확인하거나 변경할 수 있습니다. |
| **Criteria match** | 각 결과에 대해 해당 계정이 각 조건을 충족하는지 여부입니다. 이를 통해 결과의 품질을 판단할 수 있습니다. |
| **Excluded brands** | 필터링에서 제외할 브랜드로, 최근 해당 브랜드와 협업한 크리에이터를 건너뛸 수 있습니다. |

## 조건 검토하기

<Steps>
  <Step title="조건 열기">
    검색을 제출한 후 결과 상단에서 **Criteria** 또는 **See full criteria**를 선택합니다.
  </Step>
  <Step title="각 조건 확인">
    에이전트가 프롬프트를 올바르게 해석했는지 확인합니다. 예를 들어 "mid-tier"가 예상한 팔로워 범위로 변환되었는지 확인하십시오.
  </Step>
  <Step title="수정 또는 삭제">
    **Edit**을 선택하여 값을 변경합니다. **Remove criterion**을 선택하여 조건을 삭제합니다.
  </Step>
  <Step title="조건 추가">
    **Add Criteria** 또는 **Add filter**를 선택하고 필드를 고른 뒤 값을 설정하고 **Apply**를 선택합니다.
  </Step>
</Steps>

전체 요청을 다시 작성하려면 **Edit prompt**를 선택한 뒤 검색을 다시 제출하십시오.

## 사용 가능한 필터

| 필터 | 기능 |
| --- | --- |
| **Platform** | 검색할 소셜 플랫폼입니다. |
| **Followers** | 최소 및 최대 팔로워 수입니다. |
| **Engagement rate** | 최소 참여율입니다. |
| **Countries** | 크리에이터의 국가입니다. |
| **Categories** / **Sub-categories** | 크리에이터의 콘텐츠 분야입니다. |
| **Primary content language** | 크리에이터가 주로 사용하는 게시 언어입니다. |
| **Creator persona** | 크리에이터 유형입니다. 예: 리뷰어 또는 라이프스타일 브이로거. |
| **Hashtags** / **Keyword** | 크리에이터 콘텐츠에 포함된 해시태그 또는 키워드입니다. |
| **Brands** / **Excluded brands** | 크리에이터가 협업한 브랜드, 또는 제외할 브랜드입니다. |
| **Last Sponsored** | 크리에이터가 최근에 유료 콘텐츠를 게시한 시점입니다. |
| **Latest upload from** / **through** | 크리에이터의 가장 최근 업로드 날짜 범위로, 비활성 계정을 필터링합니다. |
| **Has email** / **Has contact** | 공개 연락처 정보가 있는 크리에이터만 표시합니다. |
| **Verified** / **Official Account** | 인증되거나 공식 계정만 표시합니다. |
| **Exclude contacted accounts** | 조직 내 누군가가 이미 연락한 크리에이터를 숨깁니다. |

<Tip>
  이메일 아웃리치를 계획 중이라면 **Has email**을 활성화하십시오. **Exclude contacted accounts**를 활성화하면 캠페인 전반에서 동일한 크리에이터에게 중복 연락하는 일을 방지할 수 있습니다.
</Tip>

## 결과 정렬

**Sort by**를 사용하여 결과를 정렬할 수 있습니다. 예를 들어 **Relevance**, **Followers**, **Engagement rate** 등으로 정렬할 수 있습니다. **Sort order**를 **Ascending** 또는 **Descending**으로 설정하십시오.

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="에이전트가 프롬프트를 잘못 해석했습니다. 어떻게 해야 하나요?">
    잘못된 조건을 직접 편집하십시오. 이 방법이 프롬프트를 다시 작성하는 것보다 일반적으로 더 빠릅니다. 여러 조건이 잘못되었다면 **Edit prompt**를 선택하여 더 구체적인 세부 정보를 추가하십시오.
  </Accordion>

  <Accordion title="결과가 너무 적게 나옵니다.">
    팔로워 범위를 넓히거나, 언어나 페르소나와 같은 선택적 조건을 제거하거나, 더 많은 국가를 추가해 보십시오.
  </Accordion>
</AccordionGroup>
