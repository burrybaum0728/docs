검색이 완료되면 picobean은 일치하는 크리에이터를 결과 테이블에 표시합니다. 여기서 목록을 정렬하고 좁힐 수 있으며, 각 크리에이터의 상세 정보를 열고, 더 많은 행을 요청하고, 검색을 일정에 따라 계속 실행하며, 유망한 크리에이터를 Saved 또는 캠페인으로 이동할 수 있습니다.

## 핵심 개념

| 용어 | 의미 |
| --- | --- |
| **Results table** | 검색 조건에 일치하는 크리에이터 목록으로, 각 행에 핵심 지표가 표시됩니다. |
| **Account details** | 크리에이터의 전체 데이터가 담긴 패널입니다. **Overview**, **Sponsor History**, **Memo** 탭을 포함합니다. |
| **Add more rows** | 완료된 검색의 행 제한을 늘려 더 많은 일치 크리에이터를 가져옵니다. 크레딧을 사용합니다. |
| **Monitor dataset** | 동일한 검색을 일정에 따라 다시 실행하여 시간이 지남에 따라 새로운 일치 항목이 추가되도록 합니다. 크레딧을 사용합니다. |
| **Request Admin to add to DB** | 데이터베이스에 누락된 것으로 보이는 크리에이터를 picobean 팀에 추가해 달라고 요청합니다. |

## 결과 테이블 활용하기

<Steps>
  <Step title="조건 확인">
    **See full criteria**를 선택하여 결과의 기반이 된 조건을 검토합니다. 조건을 변경하려면 [Criteria and filters](/ko/account-search/criteria-and-filters)를 참조하십시오.
  </Step>
  <Step title="정렬">
    **Sort by**를 열고 **Relevance**, **Viral**, **Name**, **Followers**, **Last Fetched**, **Last Sponsored** 중에서 선택합니다. **Order** 아래에서 **Descending** 또는 **Ascending**을 선택한 뒤 **Apply**를 선택합니다.
  </Step>
  <Step title="결과 내 검색">
    테이블 위의 검색 상자를 사용하여 현재 결과를 계정 이름, 브랜드 또는 해시태그로 필터링합니다. 이 작업은 새 검색을 실행하지 않습니다.
  </Step>
  <Step title="행 선택">
    여러 크리에이터를 한 번에 처리하려면 행을 선택합니다. 헤더 체크박스를 사용하여 해당 페이지의 모든 행을 선택하거나, 모든 페이지의 결과를 전체 선택할 수 있습니다.
  </Step>
</Steps>

| 열 | 표시 내용 |
| --- | --- |
| **Followers** | 크리에이터의 팔로워 수입니다. |
| **ER** | 참여율: 팔로워 수 대비 오디언스 반응 비율입니다. |
| **Last Sponsored** | picobean이 감지한 가장 최근 브랜드 협업입니다. |
| **Last Fetched** | picobean이 해당 크리에이터의 데이터를 마지막으로 업데이트한 시점입니다. |

<Tip>
  **Content Trend**를 선택하면 동일한 프롬프트로 Trends 페이지가 열리며, 해당 주제에서 어떤 콘텐츠가 잘 되고 있는지 확인할 수 있습니다.
</Tip>

## 계정 상세 정보 열기

행을 선택하면 크리에이터의 상세 정보가 열립니다. 이전 및 다음 화살표를 사용하면 패널을 닫지 않고 결과를 이동할 수 있으며, **Escape** 키를 누르면 패널이 닫힙니다.

| 탭 | 표시 내용 |
| --- | --- |
| **Overview** | 성과 배지, 계정 정보, 연결된 계정, 해시태그, 유료 카테고리, 콘텐츠 미리보기, 성과 차트입니다. |
| **Sponsor History** | 날짜 및 유료 아이템과 함께 감지된 브랜드 협업 내역입니다. |
| **Memo** | 팀이 해당 크리에이터에 대해 남긴 메모입니다. |

**Translate**를 활성화하면 크리에이터 이름, 해시태그, 유료 아이템, 콘텐츠 미리보기를 한국어와 영어 간에 번역할 수 있습니다. 번역되는 것은 크리에이터 콘텐츠뿐이며, 앱 인터페이스는 번역되지 않습니다.

## 더 많은 행 추가하기

<Steps>
  <Step title="Add more rows 열기">
    테이블 위에서 **Add more rows**를 선택합니다. **Total results found**에는 사용 가능한 일치 크리에이터 수가 표시됩니다.
  </Step>
  <Step title="행 제한 선택">
    프리셋을 선택하거나 직접 숫자를 입력합니다.
  </Step>
  <Step title="요청">
    **Request**를 선택합니다. 버튼에는 크레딧 비용이 표시되며, 새 행이 현재 테이블에 추가됩니다.
  </Step>
</Steps>

## 검색 모니터링

<Steps>
  <Step title="구독 열기">
    검색 제목 옆에서 **Add Subscription**을 선택합니다. 이미 모니터링 중인 검색이라면 버튼이 **Edit**로 표시됩니다.
  </Step>
  <Step title="일정 설정">
    검색 실행 주기와 매회 추가할 새 행 수를 선택합니다.
  </Step>
  <Step title="저장">
    **Save**를 선택합니다. 각 실행이 완료되면 새로운 일치 항목이 결과에 나타납니다.
  </Step>
</Steps>

<Note>
  Add more rows, Monitor dataset, CSV download는 Basic 요금제 이상이 필요합니다. 모니터링은 하루에 1 크레딧이 소모됩니다. 자세한 내용은 [Billing](/ko/account/billing)을 참조하십시오.
</Note>

## 누락된 크리에이터 요청

예상했던 크리에이터가 누락된 경우 결과 아래에서 **Request Admin to add to DB**를 선택합니다. 버튼이 **Request Sent**로 변경됩니다. 새로 추가된 크리에이터는 이후 검색에 나타납니다.

## 저장, 내보내기 및 캠페인 추가

- **Save**: 행 또는 상세 정보 패널의 북마크 아이콘을 선택한 뒤 폴더를 선택하거나 새로 만듭니다. 자세한 내용은 [Saved](/ko/influencer/saved)를 참조하십시오.
- **Export CSV**: 테이블 위의 다운로드 아이콘을 선택하여 결과를 CSV 파일로 저장합니다.
- **Add to a campaign**: 선택한 크리에이터를 캠페인 로스터에 추가합니다. 자세한 내용은 [Roster and deals](/ko/campaigns/roster-and-deals)를 참조하십시오. (Enterprise)
