picobean의 **Performance Dashboard**에서는 내 소셜 계정, 협업 중인 인플루언서, 경쟁사의 성장 현황을 시간 흐름에 따라 확인할 수 있습니다. 이 페이지에서는 계정 추가 방법, 날짜 범위 선택 방법, 핵심 지표와 성장 차트 해석 방법, 경쟁사 비교 방법, 그리고 PDF 보고서 내보내기 방법을 설명합니다.

## 사전 요구 사항

- [app.picobean.ai](https://app.picobean.ai)에 로그인한 picobean 계정.
- 모니터링할 소셜 계정 핸들이 하나 이상 있어야 합니다. (자사 계정, 인플루언서, 경쟁사 모두 가능)

<Note>
  대시보드의 일부 기능은 요금제에 따라 달라집니다. 시간에 따른 조회수와 바이럴 콘텐츠 조회수 기능을 사용하려면 **Basic** 이상의 요금제가 필요합니다. 자세한 내용은 [요금제 및 플러그인](/ko/get-started/plans-and-plugins) 페이지를 참조하세요.
</Note>

## 핵심 개념

| 용어 | 의미 |
| --- | --- |
| **My account** | 모니터링하는 자사 브랜드 계정입니다. |
| **Influencer** | 캠페인 파트너 등의 제작자 계정입니다. |
| **Competitor** | 비교를 위해 추가한 경쟁 브랜드나 제작자 계정입니다. |
| **Core metrics** | 팔로워, 콘텐츠, 조회수, 좋아요, 북마크, 공유, 댓글 요약 카드입니다. |
| **Collecting** | picobean이 해당 계정의 충분한 데이터를 수집하는 중임을 표시합니다. |
| **Last fetched** | 선택한 계정의 데이터가 마지막으로 갱신된 시점입니다. |

## 대시보드 열기

<Steps>
  <Step title="대시보드로 이동">
    왼쪽 사이드바에서 **Performance Dashboard**를 열면 **Account** 탭이 열립니다. 이 탭의 제목은 **Account performance** ("핵심 계정 지표와 경쟁사 인사이트를 한눈에 확인")입니다.
  </Step>
  <Step title="계정 선택">
    페이지 상단의 계정 체크박스를 사용해 차트에 포함할 모니터링 계정을 선택합니다.
  </Step>
  <Step title="데이터 신선도 확인">
    **Last fetched**를 확인하면 데이터가 마지막으로 갱신된 시점을 알 수 있습니다.
  </Step>
</Steps>

## 모니터링 계정 추가 및 관리

**Manage account**를 선택하면 계정 관리 화면이 열립니다. 이 화면에는 **My account**, **Competitor**, **Influencer** 세 가지 탭이 있습니다.

<Steps>
  <Step title="계정 유형 선택">
    추가할 계정 유형에 맞는 탭을 엽니다: **My account**, **Competitor**, 또는 **Influencer**.
  </Step>
  <Step title="계정 추가">
    핸들을 하나씩 추가하거나, 여러 개를 한 번에 대량 추가하거나, CSV 파일을 가져올 수 있습니다.{/* TODO: 정확한 CSV 컬럼 형식을 확인해야 함 */}
  </Step>
  <Step title="더 이상 필요 없는 계정 제거">
    목록에서 계정을 삭제하면 해당 계정에 대한 추적이 중단됩니다.
  </Step>
</Steps>

<Warning>
  모니터링 중인 계정을 삭제하면 해당 계정이 대시보드 차트와 비교에서 사라집니다. 나중에 다시 추가하면 picobean이 데이터를 다시 수집해야 할 수 있습니다.
</Warning>

<Info>
  새로 추가한 계정은 처음에 **Collecting** 상태로 표시됩니다. 14일(7일 + 7일)의 데이터가 수집되면 주간 대비 증가율이 표시됩니다. 데이터가 아직 축적 중인 날은 흐리게 표시됩니다.
</Info>

## 날짜 범위 선택

**Date range** 선택기를 열어 프리셋 중 하나를 선택합니다.

| 프리셋 | 범위 |
| --- | --- |
| **Last 7 Days** | 최근 7일 |
| **Last 14 Days** | 최근 14일 |
| **Last 30 Days** | 최근 30일 |
| **Last 90 Days** | 최근 90일 |
| **All Time** | 수집된 모든 데이터 |
| **Custom** | 달력에서 시작일과 종료일을 선택한 뒤 **Apply**를 선택합니다 |

모든 카드와 차트가 선택한 범위에 맞게 갱신됩니다. 비교는 **Current Period**와 같은 길이의 **Previous Period**를 사용합니다. 예를 들어 7일을 선택하면 **This week** 대비 **Previous week**로 비교합니다.

## 핵심 지표 읽기

**Core metrics** 섹션에서는 선택한 계정의 핵심 지표를 요약합니다.

| 카드 | 표시 내용 |
| --- | --- |
| **Followers** | 팔로워 수와 해당 기간 동안의 순 증감 |
| **Contents** | 게시된 업로드 수 |
| **Views** | 해당 기간에 업로드된 콘텐츠의 총 조회수 |
| **Likes** | 해당 기간에 업로드된 콘텐츠의 총 좋아요 수 |
| **Bookmarks** | 해당 기간에 업로드된 콘텐츠의 총 북마크 수 |
| **Shares** | 해당 기간에 업로드된 콘텐츠의 총 공유 수 |
| **Comments** | 해당 기간에 업로드된 콘텐츠의 총 댓글 수 |

각 카드에는 스파크라인과 **vs Prev. Period** 기준 변화가 포함됩니다. 카드 위에 마우스를 올리면 정확한 합계가 표시됩니다.

<Tip>
  조회수, 좋아요, 북마크, 공유, 댓글은 범위 내 **각 날짜에 업로드된 콘텐츠**에 대해 집계되며, 해당 기간 동안 발생한 모든 활동을 의미하는 것이 아닙니다. 범위 이전에 게시된 글은 집계에 포함되지 않습니다.
</Tip>

## 성장 차트 분석

- **Account growth**: 시간에 따른 **Followers**와 **Contents**를 나타냅니다. **Daily**와 **Cumulative** 값 사이를 전환할 수 있습니다.
- **Engagement growth**: 각 날짜에 업로드된 콘텐츠의 **Views**, **Likes**, **Bookmarks**, **Shares**, **Comments**를 나타냅니다.

각 차트에는 **Total**, **Gain**, **Gain %** 및 이전 기간 대비 변화를 보여주는 순위표가 포함됩니다.

## 경쟁사 비교

**Compare competitors**를 켜면 경쟁사 계정이 차트 위에 겹쳐 표시되고 **Competitor comparison analysis**가 열립니다. 테이블을 **Ranking**, **Account**, 또는 **Gain %** 순으로 정렬하여 누가 가장 빠르게 성장하는지 확인할 수 있습니다. 또 다른 경쟁사를 추가하려면 **Add competitor**를 선택합니다.

## PDF 보고서 내보내기

**Download PDF**를 선택하면 현재 보고 있는 화면(선택된 범위, 카드, 차트 포함)을 PDF로 내보냅니다. **PDF export failed** 메시지가 나타나면 다시 시도하거나 브라우저의 인쇄 기능을 사용해 PDF로 저장하세요.
