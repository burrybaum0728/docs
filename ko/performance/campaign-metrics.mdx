각 picobean 캠페인에는 전용 **Performance** 탭이 있으며, 여기서 외부 전달 결과, 로스터 진행 상황, 그리고 시드 이후 제작자가 게시한 콘텐츠를 추적할 수 있습니다. 이메일이 발송되고 제작자가 게시물을 올리면 숫자가 자동으로 갱신되므로 별도의 보고서를 작성할 필요가 없습니다.

## 사전 요구 사항

- Enterprise 요금제가 필요합니다. (캠페인은 Enterprise 전용 기능입니다.)
- 로스터가 포함된 캠페인이 하나 이상 생성되어 있어야 합니다.
- 퍼널에 데이터가 표시되려면 일부 제작자에게 이메일을 발송했거나 시드 완료 상태로 표시해야 합니다.

## 이메일 결과 검토

캠페인을 연 다음 **Performance** 탭을 선택하면 페이지 상단에 전달 지표를 위한 두 개의 연결된 블록이 표시됩니다.

### 이메일 성과 퍼널

이것은 캠페인을 통해 발송된 모든 메시지를 4단계로 분석하는 연결된 막대 차트입니다.

| 단계 | 설명 |
| --- | --- |
| **Total sent** | 캠페인에서 발송한 이메일 수입니다. |
| **Total delivered** | 수신자의 메일함에 도달한 메시지 수입니다. |
| **Total open** | 수신자가 연 메시지 수입니다. |
| **Total replied** | 답변을 받은 메시지 수입니다. |

- 각 막대는 총 발송 수에 대한 상대적 크기를 보여줍니다.
- 단계 사이에는 전환율이 표시됩니다. (예: 발송 대비 72% 수신 완료)
- 새 이메일이 발송되면 차트가 자동으로 갱신됩니다.

### 캠페인 이메일 요약

퍼널 옆에 쌓인 지표 카드에는 동일한 4가지 숫자가 표시되며, 총 발송 대비 비율을 나타내는 부가 라벨이 포함됩니다.

- **Total sent**: 원시 수치입니다.
- **Total delivered**, **Total open**, **Total replied**: 수치와 "총 발송의 X%"입니다.

<Note>
  이메일 수신 완료, 열람, 답변 추적 기능을 사용하려면 연결된 메일박스가 필요합니다. 이 숫자들이 계속 0으로 표시되면 [메일박스 연결](/ko/email/connect-mailbox) 페이지를 참조하세요.
</Note>

## 로스터 진행 상황 추적

이메일 섹션 아래에 있는 **Campaign progress** 퍼널에는 워크플로우의 각 단계를 통과한 제작자 수가 표시됩니다.

| 단계 | 의미 |
| --- | --- |
| **Target List** | 로스터에 추가된 제작자입니다. |
| **Sent (Email / DM)** | 외부 전달을 발송했습니다. |
| **Negotiating** | 협의가 진행 중입니다. |
| **Confirmed** | 협업이 확인되었습니다. |
| **Package sent** | 제품이 발송되었습니다. |
| **Content confirmed** | 게시물 초안이나 가이드라인이 승인되었습니다. |
| **Uploaded** | 콘텐츠가 게시되었습니다. |

- 첫 번째 막대는 항상 100%이며 타겟 리스트의 총 제작자 수와 같습니다.
- 이후 막대는 각 단계에 도달한 제작자 수에 따라 확대되거나 축소됩니다.
- 막대 위에는 단계 간 전환율이 표시됩니다.
- 로스터가 비어 있으면 퍼널은 0으로 표시되고 제작자를 발견할 수 있는 **View recommendations** 버튼이 제공됩니다.

<Steps>
  <Step title="단계별 필터링">
    퍼널에 클릭 가능한 단계가 표시되면 해당 단계를 선택하면 Target List 탭의 로스터 테이블이 해당 단계의 제작자만 필터링됩니다.
  </Step>
  <Step title="로스터 편집 후 새로고침">
    앱의 다른 곳에서 제작자를 새 상태로 이동하면 퍼널이 수 초 내에 갱신됩니다.
  </Step>
</Steps>

## 업로드된 콘텐츠 성과 검사

**Content performance** 섹션에는 제작자가 시드 완료로 표시된 후 캠페인과 매칭된 모든 게시물이 나열됩니다.

### 키워드 필터

콘텐츠는 캠페인 브리프에 저장된 키워드로 자동 필터링됩니다. 현재 필터의 소스는 다음 힌트로 표시됩니다.

| 소스 힌트 | 의미 |
| --- | --- |
| Keyword filter is cleared | 시드 이후 게시된 모든 게시물이 집계됩니다. |
| Auto-filtered by the campaign's product names | 캠페인 제품명이 키워드로 사용됩니다. |
| Auto-filtered by your org's brand keywords | 조직 브랜드 키워드가 적용됩니다. |
| No keywords set | 시드 이후 게시된 모든 게시물이 집계됩니다. |

- 섹션 상단의 키워드 입력란에서 사용자 정의 키워드를 추가할 수 있습니다.
- 모든 키워드를 제거하면 필터가 해제되고 매칭된 모든 게시물이 집계됩니다.
- 키워드를 추가하면 자동 소스가 무시됩니다.

### 콘텐츠 테이블 열

테이블에는 매칭된 게시물이 한 행씩 표시되며 다음 열이 포함됩니다.

| 열 | 표시 내용 |
| --- | --- |
| **Preview** | 게시물 썸네일과 제목 |
| **Account** | 제작자 이름, 핸들, 플랫폼 배지 |
| **Upload date** | 게시물이 게시된 날짜 |
| **Views** | 조회수 |
| **Likes** | 좋아요 수 |
| **Comments** | 댓글 수 |
| **Shares** | 공유/재게시 수 |
| **Bookmarks** | 저장 수 |
| **ER** | 좋아요와 댓글을 조회수 대비로 계산한 참여율 |

- 헤더 메뉴를 통해 열 기준으로 테이블을 정렬할 수 있습니다.
- **NEW** 배지가 붙은 행은 마지막 방문 이후 감지된 콘텐츠를 나타냅니다.
- 행을 클릭하면 게시물 이미지, 캡션, 해시태그, 계정 정보가 포함된 상세 패널이 열립니다.

### 타임라인 차트

누적 선형 차트는 시간에 따른 캠페인 콘텐츠 궤적을 보여줍니다.

- 차트 상단에서 측정항목을 선택할 수 있습니다: **Views**, **Likes**, **Bookmarks**, 또는 **Shares**.
- 데이터는 짧은 캠페인의 경우 일 단위로, 21일 이상의 캠페인의 경우 주 단위로 그룹화됩니다.
- 각 포인트는 누적값입니다: 새 매칭 콘텐츠를 실행 합계에 추가합니다.

### 상태 도넛 차트

타임라인 옆의 도넛 차트는 현재 로스터 상태 분포를 보여줍니다.

| 조각 | 색상 | 의미 |
| --- | --- | --- |
| **Posted** | 녹색 | 매칭된 콘텐츠가 게시된 제작자 |
| **Product sent · awaiting post** | 밝은 녹색 | 시드 완료했으나 아직 게시하지 않은 제작자 |
| **Contacted** | 파란색 | 전달을 발송했으나 시드 완료 또는 확인 전 |
| **Prospect** | 회색 | 로스터에 추가되었으나 아직 연락하지 않음 |
| **Not participating** | 회색 | 거절하거나 제거됨 |

- 조각 위에 마우스를 올리면 정확한 수와 비율을 볼 수 있습니다.
- 범례에서 제작자 이름을 클릭하면 해당 프로필 페이지가 열립니다.

### 콘텐츠 수동 추가

시스템이 아직 크롤링하지 않은 URL을 제작자가 공유한 경우 **Add by URL**에 URL을 붙여넣을 수 있습니다.

- 핸들이 포함된 URL은 게시물이 즉시 추가됩니다. | 핸들이 없는 URL(예: 일부 Instagram 공유 링크)의 경우 **Creator handle needed** 프롬프트가 나타납니다. 제작자의 `@handle`을 입력한 뒤 **Add**를 클릭하면 picobean이 해당 게시물을 수집할 수 있습니다.
- 이렇게 추가된 게시물은 수집되면 테이블에 표시됩니다.

<Warning>
  성과 테이블에서 콘텐츠를 제거하면 해당 콘텐츠가 통계에서 제외됩니다. 되돌리려면 URL을 다시 추가하세요.
</Warning>

<Steps>
  <Step title="콘텐츠 결과 내보내기">
    콘텐츠 테이블 우측 상단의 **Download CSV**를 클릭하면 모든 매칭 게시물과 조회수, 좋아요 수, 댓글 수, 공유 수, 저장 수를 포함한 CSV 파일을 내보냅니다.
  </Step>
</Steps>

## 발송 수신자 검토

**Sent recipients** 섹션에는 캠페인에서 이메일을 수신한 모든 고유 이메일 주소가 나열됩니다.

### 테이블 열

| 열 | 표시 내용 |
| --- | --- |
| **Recipient** | 아바타, 표시 이름, 매칭된 경우 플랫폼 핸들 |
| **Email** | 메시지를 수신한 이메일 주소 |
| **Sent emails** | 해당 주소로 발송된 총 이메일 수 |
| **Last sent** | 가장 최근 메시지의 타임스탬프 |
| **Recent subject** | 최신 이메일의 제목 |
| **Status** | 배달 상태와 후속 단계 상황 |

### 배달 상태 배지

| 배지 | 의미 |
| --- | --- |
| **Opened** | 수신자가 이메일을 한 번 이상 열었습니다. |
| **Not opened** | 수신 완료되었으나 아직 열지 않았습니다. |
| **Bounced** | 이메일을 배달할 수 없었습니다. |
| **Spammed** | 수신자의 서버에서 스팸으로 표시했습니다. |

### 후속 단계 배지

| 배지 | 의미 |
| --- | --- |
| **Replied** | 제작자가 답변했습니다. |
| **Follow-up** | 후속 이메일을 발송했습니다. |
| **Resend queued** | 재발송이 예약되었습니다. |
| **No follow-up** | 첫 번째 메시지 이후 추가 이메일을 발송하지 않았습니다. |

### 대화 타임라인

수신자를 선택하면 해당 수신자와 주고받은 모든 메시지 타임라인이 포함된 측면 패널이 열립니다.

| 이벤트 | 의미 |
| --- | --- |
| **Email sent** | 첫 아웃바운드 메시지입니다. |
| **Reply sent** | 팀이 답변을 보냈습니다. |
| **Reply received** | 제작자가 답변했습니다. |

<Note>
  시스템은 각 이메일을 제작자 프로필과 자동으로 매칭하려고 시도합니다. 매칭에 실패해도 해당 수신자는 이메일 주소만으로 목록에 계속 표시됩니다.
</Note>

## 결과

Performance 탭을 연 후에는 다음을 확인할 수 있어야 합니다.

- 발송, 수신 완료, 열람, 답변 수가 표시된 명확한 이메일 퍼널
- 타겟 리스트부터 업로드된 콘텐츠까지의 로스터 진행 퍼널
- 정렬 가능한 열, 누적 타임라인, 상태 도넛 차트가 포함된 매칭 제작자 콘텐츠 순위 목록
- 배달 상태와 대화 타임라인이 포함된 완전한 발송 수신자 목록
