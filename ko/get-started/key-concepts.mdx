picobean은 기능 전반에 거쳐 소수의 용어를 사용합니다. 이 용어들을 한 번 익히면 가이드의 모든 페이지를 더 쉽게 이해할 수 있습니다. 이 페이지에서는 제품 영역별로 용어를 묶고, 각 항목을 자세히 다루는 페이지로 연결합니다.

## 워크스페이스와 플랜

| 용어 | 의미 |
| --- | --- |
| **Organization** | 팀의 공유 워크스페이스입니다. 멤버는 폴더, 메모, 캠페인, 연락 기록을 공유합니다. |
| **Plan** | 구독 등급입니다. Basic, Enterprise 등 어떤 기능이 활성화되는지를 결정합니다. |
| **Plugin** | Settings에서 켜고 끌 수 있는 기능 세트입니다. **Influencer Affiliate** 또는 **Trend Research**를 선택할 수 있습니다. |
| **Credit** | 검색과 에이전트 요청에 소모되는 사용량 단위입니다. |

자세한 내용은 [Plans and plugins](/ko/get-started/plans-and-plugins)에서 확인하세요.

## 계정 검색

| 용어 | 의미 |
| --- | --- |
| **Prompt** | 원하는 크리에이터나 콘텐츠를 평문으로 설명한 내용입니다. |
| **Criteria** | 프롬프트에서 에이전트가 추출한 구조화된 필터입니다. |
| **Row limit** | 에이전트가 수집하는 일치 계정의 개수입니다. |
| **Saved folder** | 나중을 위해 저장한 크리에이터 목록입니다. |
| **Memo** | 크리에이터에 첨부된 팀 노트입니다. |

자세한 내용은 [AI search](/ko/account-search/ai-search)에서 확인하세요.

## 캠페인

| 용어 | 의미 |
| --- | --- |
| **Campaign** | 브리프, 명단, 이메일, 예산을 포함하는 하나의 시딩 프로그램입니다. |
| **Unpaid / Paid seeding** | 제품 증정만 하는 경우와 제품 증정 및 수수료를 지급하는 경우입니다. |
| **Roster status** | 크리에이터의 진행 단계입니다. Prospect, Contacted, Negotiating, Confirmed, Product sent, Posted, Not participation 중 하나입니다. |
| **Deal** | 한 명의 크리에이터와 체결한 수수료 협상 내역입니다. 장부에 기록됩니다. |
| **Content guideline** | 초안 검토 시 반드시 포함하거나 피해야 할 규칙입니다. |

자세한 내용은 [Campaign overview](/ko/campaigns/overview)에서 확인하세요.

## 이메일 아웃리치

| 용어 | 의미 |
| --- | --- |
| **Linked mailbox** | 캠페인 이메일 발송에 사용하는 Gmail 또는 Outlook 계정입니다. |
| **Template** / **Variable** | `{{creator_name}}`과 같은 자리 표시자를 포함한 재사용 가능한 이메일입니다. |
| **Sequence** | 안내 이메일과 자동 재전송 이메일로 구성된 시퀀스입니다. |
| **Seeding agent** | 답변을 읽고 답장을 작성하거나 발송하는 AI입니다. |
| **Approval queue** | 에이전트가 작성한 답장이 승인을 기다리는 공간입니다. |

자세한 내용은 [Connect a mailbox](/ko/email/connect-mailbox)에서 확인하세요.

## 성과와 트렌드

| 용어 | 의미 |
| --- | --- |
| **My account / Competitor / My influencer** | Performance Dashboard에서 추적하는 세 가지 콘텐츠 소스입니다. |
| **Gain %** | 이전 기간과 비교한 변화율입니다. |
| **Content tag** | Paid, Affiliate, Hook 등 AI가 부여한 라벨입니다. |
| **Trend** / **Meme** | Trend Research가 감지한 상승 중인 주제, 해시태그, 형식입니다. |

자세한 내용은 [Performance Dashboard](/ko/performance/dashboard)와 [Trends](/ko/trends/trends)에서 확인하세요.
