picobean은 두 가지 방식으로 기능을 제어합니다. \*\*플러그인(Plugin)\*\*은 사이드바에 나타나는 탭을 결정하고, \*\*결제 플랜(Plan)\*\*은 해당 탭 안에서 사용할 수 있는 기능을 결정합니다. 여러 플러그인을 동시에 활성화할 수 있으며, 모든 계정은 Free 플랜으로 시작합니다. 이 페이지에서는 두 가지를 설명하고 어떤 기능에 어떤 플랜이 필요한지 안내합니다.

## 핵심 개념

| 용어 | 의미 |
| --- | --- |
| **Plugin** | 사이드바에 탭을 추가하는 기능 세트입니다. |
| **Plan** | 조직의 구독 단계입니다. Free, Basic, Enterprise 중 하나입니다. |
| **Locked feature** | 현재 플랜에 포함되지 않은 기능입니다. 사용을 시도하면 업그레이드 안내 메시지가 표시됩니다. |

### 플러그인 켜기 및 끄기

<Steps>
  <Step title="Settings 열기">
    사이드바에서 **Settings**를 선택하면 **Account** 탭이 열립니다.
  </Step>
  <Step title="Plugin Selection 찾기">
    **Plugin Selection** 카드를 찾습니다.
  </Step>
  <Step title="플러그인 선택">
    원하는 플러그인을 체크합니다. 활성화된 플러그인은 **In use**로 표시됩니다.
  </Step>
  <Step title="저장">
    **Save**를 선택하면 사이드바가 즉시 업데이트됩니다.
  </Step>
</Steps>

<Note>
  Settings와 결제 페이지는 어떤 플러그인을 켜든 항상 사용할 수 있습니다. 플러그인을 끄면 해당 탭이 사라지고 해당 페이지는 URL로도 열 수 없습니다.
</Note>

## 플랜

조직의 플랜은 **Settings**에서 확인할 수 있습니다. 가격과 크레딧 정보는 [Billing](/ko/account/billing) 페이지에서 확인하세요.

### 플랜별 기능 제공 여부

| 기능 | Free | Basic | Enterprise |
| --- | --- | --- | --- |
| 저장 목록, 폴더, 북마크, 메모 | Yes | Yes | Yes |
| 번역 | Yes | Yes | Yes |
| AI 계정 검색 | No | Yes | Yes |
| 데이터셋 모니터링 및 행 추가 | No | Yes | Yes |
| CSV 다운로드 | No | Yes | Yes |
| 전체 콘텐츠 분석 | No | Yes | Yes |
| 바이럴 콘텐츠 대시보드 및 시간대별 조회수 | No | Yes | Yes |
| 캠페인 관리 | No | No | Yes |
| 메일박스 관리 및 이메일 발송 | No | No | Yes |
| 팀 멤버 초대 | No | No | Yes |
| Private DB(My accounts) | No | No | Yes |
| 콘텐츠 업로드 | No | No | Yes |

현재 플랜에 포함되지 않은 기능을 시도하면 picobean이 업그레이드 메시지를 표시합니다. Enterprise 전용 기능의 경우 "This feature is only available on the Enterprise plan."이라고 표시됩니다.
