크리에이터가 참여를 확정하면 다음 단계는 제품 배송입니다. picobean은 주소 수집부터 배달까지 모든 택배를 추적하며, 배송 상세 정보, 운송장 링크, CSV 내보내기를 위한 전용 테이블을 제공합니다.

<Note>
  캠페인은 **Enterprise** 플랜에서만 이용할 수 있습니다.
</Note>

## 배송 탭 열기

캠페인 내부에서 **Shipping & Tracking**을 클릭하면 이행 화면이 열립니다. 단계가 **Confirmed** 이상인 크리에이터만 여기에 표시됩니다. Prospect 또는 단순히 Contacted 상태의 크리에이터는 필터링되어 실제 배송 업무를 하는 테이블에 맞춰집니다.

## 배송 요약 카드

상단에는 4개의 카드로 현재 이행 상태를 보여줍니다:

| 카드 | 설명 |
| --- | --- |
| Address collected | 저장된 배송 주소가 있는 크리에이터입니다. |
| Address missing | 주소가 아직 필요한 Confirmed 크리에이터입니다. |
| Shipped | 운송장 번호가 있고 배송 처리된 제품입니다. |
| Delivered | 배달 완료로 표시된 제품입니다. |

이 숫자들은 크리에이터의 배송 상태를 변경하거나 주소를 저장하면 자동으로 업데이트됩니다.

## 배송 테이블

테이블은 확정된 크리에이터당 한 행씩 나열합니다.

| 컬럼 | 설명 |
| --- | --- |
| Creator ID | 핸들과 프로필 사진입니다. |
| Creator name | 표시 이름입니다. |
| Address | 저장된 배송 정보의 거리 주소입니다. |
| Tracking | 택배사 공식 추적 페이지 링크가 있는 경우 운송장 번호입니다. |
| Carrier | 택배사 이름입니다. |
| Link | 택배사 추적 페이지를 새 탭으로 여는 **Track** 바로가기 링크입니다. |
| Status | 현재 이행 상태입니다. |
| Updated | 마지막 배송 관련 변경의 타임스탬프입니다. |

검색 바를 사용하여 크리에이터 이름, 주소, 운송장 번호로 필터링할 수 있습니다. **Status** 드롭다운을 사용하여 단일 이행 상태로 필터링할 수 있습니다.

## 이행 상태

아무 행의 **Status** 셀을 클릭하여 이행 단계를 변경합니다.

| 상태 | 의미 |
| --- | --- |
| No address | 배송 주소가 수집되지 않았습니다. |
| Address collected | 주소가 저장되어 배송 준비가 되었습니다. |
| Shipped | 제품이 발송되었습니다. 운송장 번호가 필요합니다. |
| Delivered | 제품이 크리에이터 주소에 도착했습니다. |

상태 변경 시 테이블이 즉시 업데이트됩니다. 변경을 저장할 수 없는 경우, 해당 행은 이전 상태로 돌아가고 오류 메시지가 나타납니다.

## 운송장 번호 등록 또는 편집

운송장 번호가 없는 크리에이터에 대해는 **Tracking** 컬럼에서 **Register**를 클릭하고, 기존 운송장 번호가 있는 경우에는 번호를 클릭하여 편집합니다. 두 개의 필드가 있는 대화상자가 열립니다:

| 필드 | 설명 |
| --- | --- |
| Carrier | 드롭다운에서 선택합니다. |
| Tracking number | 택배사 추적 코드를 입력합니다. |

### 지원 택배사

드롭다운에는 다음이 포함됩니다:

- USPS
- UPS
- FedEx
- DHL
- Amazon Logistics
- Other

한국 택배사(CJ대한통운, 한진택배, 롯데택배, 우체국택배, 쿠팡) 또는 Royal Mail을 사용한 기록도 계속 정상 작동합니다. 지원되는 택배사를 선택하면 **Track** 링크가 택배사 공식 추적 페이지를 직접 엽니다. 알 수 없는 택배사는 추적 URL을 생성하지 않습니다.

**Register**를 클릭하여 저장하거나, 편집 시에는 **Save changes**를 클릭합니다. 테이블이 새 운송장 번호와 클릭 가능한 **Track** 링크로 업데이트됩니다.

## 배송 상세 패널

아무 행이나 클릭하면 우측 상세 패널이 열립니다.

### 주소 필드

| 필드 | 설명 |
| --- | --- |
| Recipient name | 수령인 이름입니다. |
| Address | 거리 주소입니다(1줄과 2줄은 결합되어 표시됩니다). |
| City | 도시명입니다. |
| State | 주 또는 도입니다. |
| Zip code | 우편번호입니다. |
| Phone number | 배송 연락처 전화번호입니다. |

아무 필드나 편집한 후 **Save**를 클릭하여 주소를 저장합니다. **Clear address**를 클릭하면 저장된 모든 주소 데이터가 삭제되고 해당 크리에이터는 **No address** 상태로 돌아갑니다.

### 추적 섹션

운송장 번호가 있으면 패널에 택배사와 운송장 코드가 **Track** 링크와 함께 표시됩니다. **Edit tracking**을 클릭하면 택배사 또는 번호를 변경할 수 있습니다.

### 추적 이벤트

패널에는 배송 관련 딜 이벤트 타임라인이 표시됩니다:

| 이벤트 | 표시 시기 |
| --- | --- |
| Address requested | 주소 요청 이메일이 전송되었을 때입니다. |
| Address collected | 주소가 저장되었을 때입니다. |
| Shipping confirmed | 배송 안내가 전송되었을 때입니다. |
| Package shipped | 제품이 배송 처리되었을 때입니다. |
| Package delivered | 제품이 배달 처리되었을 때입니다. |

각 이벤트는 타임스탬프와 관련 시 택배사 및 운송장 번호를 표시합니다.

## 배송 CSV 내보내기

배송 탭 우측 상단에서 **Download CSV**를 클릭합니다. 내보내기는 현재 필터 범위를 포함합니다:

| 필터 | CSV 범위 |
| --- | --- |
| All statuses | 모든 Confirmed 크리에이터입니다. |
| No address | 주소가 없는 크리에이터입니다. |
| Address collected | 주소는 있지만 아직 배송되지 않은 크리에이터입니다. |
| Shipped | 배송 또는 배달 상태의 크리에이터입니다. |
| Delivered | 배달 상태의 크리에이터입니다. |

CSV에는 크리에이터 이름, 핸들, 주소, 도시, 주, 우편번호, 전화번호, 수령인 이름, 운송장 번호, 택배사, 상태가 포함됩니다. 다운로드 시 행 수와 파일명이 토스트 메시지로 표시됩니다.
