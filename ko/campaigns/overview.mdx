picobean 캠페인은 브리핑부터 정산까지 인플루언서 협업 전 과정을 한곳에서 관리합니다. 각 캠페인에는 브리프, 타겟 크리에이터 로스터, 이메일 템플릿 세트가 포함되며, 아웃리치, 협상, 배송, 콘텐츠 검수, 결제까지 진행 상황을 탭으로 추적합니다.

<Note>
  캠페인은 **Enterprise** 플랜에서만 이용할 수 있습니다. Basic 및 Free 플랜에서는 Campaign 메뉴가 보이지 않습니다.
</Note>

## 캠페인 목록 페이지

사이드바에서 **Campaign**을 열면 워크스페이스의 모든 캠페인을 볼 수 있습니다.

| 컬럼 | 설명 |
| --- | --- |
| Campaign | 제목, 설명 미리보기, 생성일자입니다. |
| Status | 현재 캠페인 상태로, 예를 들어 Draft 또는 Active입니다. |
| Type | Unpaid seeding 또는 Paid seeding입니다. |
| Progress | 로스터가 퍼널에서 얼마나 진행되었는지 보여주는 시각적 바입니다. |
| Due | 설정된 캠페인 종료일입니다. |
| Actions | 캠페인 상세 보기로 이동합니다. |

캠페인 제목을 클릭하면 **Overview** 탭이 열립니다.

## Overview 탭 레이아웃

캠페인 상세 페이지는 Overview 탭에서 열리며, 여러 카드로 구성되어 있습니다:

- **Brief**: 편집 가능한 캠페인 이름, 설명, 제품, 일정, 예산, 타겟 채널, 타겟 국가입니다.
- **To do now**: AI가 생성한 답변 승인 대기나 수신된 회신 수동 답변 등 사람의 개입이 필요한 작업입니다.
- **Campaign progress**: 각 단계에 얼마나 많은 크리에이터가 있는지 보여주는 7단계 퍼널입니다.
- **Seeding goal progress**: 참여 확정 또는 그 이상으로 진행된 크리에이터 수의 목표 대비 비율입니다.
- **Budget**: 총 예산, 할당 금액, 잔액, 그리고 확정된 딜 목록입니다.
- **Assigned templates**: 할당된 첫 발송 템플릿, 회신 템플릿, 캠페인 가이드, 제품 배송 템플릿입니다.

Brief 카드에서 **Edit**을 눌러 필드를 수정할 수 있습니다. **Save**를 눌러 저장하거나, **Cancel**을 눌러 취소합니다.

## 캠페인 진행 퍼널

퍼널은 크리에이터가 타겟 리스트에서 게시된 콘텐츠까지 어떻게 이동하는지 보여줍니다. 각 단계는 배타적입니다: 한 명의 크리에이터는 도달한 가장 높은 단계에만 집계됩니다.

| 단계 | UI 라벨 | 의미 |
| --- | --- | --- |
| Target List | Target List | 로스터에 추가되었지만 아웃리치가 아직 전송되지 않았습니다. |
| Sent | Sent (Email / DM) | 첫 아웃리치 이메일 또는 DM이 전송되었습니다. |
| Negotiating | Negotiating | 크리에이터가 회신하고 대화가 진행 중입니다. 가이드 전송, 초안 제출, 또는 수정 요청도 포함됩니다. |
| Confirmed | Confirmed | 딜이 합의되었거나(유료) 참여가 확정되었습니다(무료). |
| Package Sent | Package sent | 제품이 크리에이터에게 배송되었습니다. |
| Content Confirmed | Content confirmed | 초안 콘텐츠가 검수를 통과하여 게시가 승인되었습니다. |
| Uploaded | Uploaded | 크리에이터가 콘텐츠를 게시했고 picobean이 해당 캠페인과 매칭했습니다. |

퍼널에는 단계별 전환율도 백분율로 표시됩니다.

**View recommendations**를 클릭하면 타겟 리스트를 열어 더 많은 크리에이터를 추가할 수 있습니다.

## 로스터 생명주기 단계

각 로스터에 있는 크리에이터는 하나의 표시 단계를 가집니다. 해당 단계는 저장된 로스터 상태와 딜 협상 상태의 조합으로 결정됩니다.

| 단계 | 배지 색상 | 아이콘 | 사용 시기 |
| --- | --- | --- | --- |
| Prospect | 슬레이트 그레이 | Minus | 아직 아웃리치가 전송되지 않았습니다. |
| Contacted | 스카이 블루 | Single check | 아웃리치가 전송되었습니다. |
| Negotiating | 앰버 | Clock | 대화가 진행 중입니다. |
| Confirmed | 라임 그린 | Double check | 딜이 합의되었거나 참여가 확정되었습니다. |
| Product sent | 스카이 블루 | Single check | 제품이 배송되었습니다. |
| Posted | 라임 그린 | Double check | 콘텐츠가 업로드 및 매칭되었습니다. |
| Not participating | 로즈 레드 | X | 크리에이터가 거절했거나 거절 처리되었습니다. |

크리에이터의 상태 칩을 클릭하면 팝오버가 열려 단계를 수동으로 변경할 수 있습니다. **Negotiating** 또는 **Confirmed**를 선택하면 딜 상태가 업데이트되고, **Product sent** 또는 **Posted**를 선택하면 로스터 상태가 업데이트됩니다. **Not participating**에서 **Product sent** 또는 **Posted**로 직접 이동할 때는, 참여자로 다시 처리됨을 안내하는 확인 대화상자가 나타납니다.

## "To do now" 카드 이해하기

이 카드는 사용자의 주의가 필요한 항목을 보여줍니다.

| 구역 | 표시 내용 |
| --- | --- |
| Review AI draft | 에이전트 생성 답변 중 승인 대기 중이거나 전송에 실패한 항목입니다. |
| Needs reply | 분류기가 수동 답변을 권장하는 수신 회신입니다. |
| Send guide | 합의한 크리에이터 중 캠페인 가이드를 기다리는 대상입니다. |
| Request address | 배송 주소가 아직 수집되지 않은 확정된 크리에이터입니다. |

각 항목에는 크리에이터 이름, 이메일, 필요한 조치에 대한 한 줄 요약이 표시됩니다. **Review**를 클릭하면 Mailbox에서 초안을 확인할 수 있고, **Handle in Mailbox**를 클릭하면 해당 대화로 이동합니다.
