**Settings**에서는 개인 프로필, 앱 언어, 플러그인, 알림을 설정합니다. **Account** 탭과 **Usage & Billing** 탭 두 개가 있으며, 이 페이지에서는 **Account** 탭을 다룹니다. 요금제, 크레딧, 인보이스 관리는 [Billing](/ko/account/billing)를 참조하세요.

## 주요 개념

| 용어 | 의미 |
| --- | --- |
| **Plugin Selection** | 사이드바에 표시할 기능 세트입니다. |
| **Organization** | 사용자가 속한 워크스페이스입니다. 온보딩 과정에서 설정합니다. |
| **Notification preferences** | 발송 실패 및 주간 구독 요약 메일 수신 여부를 설정합니다. |

## Account 탭

| 구역 | 할 수 있는 일 |
| --- | --- |
| **Your Details** | **Name**과 **Email**을 확인합니다. 이름을 수정하려면 **Change Settings**를 선택하세요. 이메일 계정은 **Change Password**가 표시됩니다. 이메일 주소는 로그인 제공자로부터 가져오며 변경할 수 없습니다. |
| **Organization** | **Organization Name**을 확인합니다. 멤버 관리는 [Team and Members](/ko/account/team-and-members)를 참조하세요. |
| **Plugin Selection** | 사이드바에 표시할 기능 세트를 선택합니다. |
| **Language** | 앱 전체를 **English** 또는 **Korean**으로 전환합니다. |
| **Dark Mode** | 다크 모드를 켜거나 끕니다. 사이드바 하단의 토글에서도 전환할 수 있습니다. |
| **Mailbox Management** | 발신 메일박스를 연결하거나 해제합니다(Enterprise). 자세한 내용은 [Connect a mailbox](/ko/email/connect-mailbox)를 참조하세요. |
| **Notification Preferences** | 이메일 알림 수신 여부를 설정합니다. |

## 플러그인 선택

<Steps>
  <Step title="Plugin Selection 열기">
    **Settings** > **Account**로 이동한 뒤 **Plugin Selection** 카드를 찾습니다.
  </Step>
  <Step title="플러그인 선택">
    필요한 플러그인을 선택합니다. 기본적으로 켜져 있는 **Influencer Affiliate**와 **Trend Research** 중에서 선택할 수 있습니다. 각 플러그인이 추가하는 탭은 [Plans and plugins](/ko/get-started/plans-and-plugins)를 참조하세요.
  </Step>
  <Step title="저장">
    **Save**를 선택하면 사이드바가 즉시 업데이트됩니다.
  </Step>
</Steps>

## 알림 설정

| 알림 | 발송 시점 |
| --- | --- |
| **Send Failure Alarm** | 캠페인 이메일 발송에 실패했을 때 |
| **Subscription Weekly Alerts** | 신규 크리에이터를 요약한 주간 다이제스트 |

**Change Settings**를 선택한 뒤 원하는 알림을 켜거나 끄고, **Save Settings**를 선택합니다.

<Tip>
  캠페인 실행 중에는 **Send Failure Alarm**을 켜두세요. 그래야 반송되거나 실패한 아웃리치를 빠르게 확인할 수 있습니다.
</Tip>
